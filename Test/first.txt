Q1. What do you know about functions?
A1. 1)A function is a reusable block of code that performs a specific task.
    2)We can write it once inside a function and call it whenever needed.

Q2. what is layout?
A2. 1)A layout is the pre-planned structure or arrangement of elements on a web page. 
    2)It determines where different sections such as the header, navigation bar, main content and footer are placed to create an organized design.

Q3. what do you know about flex layout?
A3. 1)Flex Layout is a CSS layout model used to arrange and align elements efficiently inside a container. 
    2)It helps create responsive and flexible web page.

Q4. what is the need of grid layout?
A4. 1)CSS Grid Layout is used to create two-dimensional web page layouts. 
    2)It allows developers to arrange elements in both rows and columns simultaneously.
    3) It makes it ideal for designing complex and responsive web pages.
    
Q5. what is the use of github?
A5. 1)GitHub is a cloud-based platform where developers store,manage and share their code.
    2)It helps developers share projects, track changes and collaborate with others.
